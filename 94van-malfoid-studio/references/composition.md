# 画面组件与拼装

用文字指定主体，从下面八类组件中各取所需项，再补充数量、材质、文字和画幅。一个主域决定画面的目的，其他组件负责把画面具体化。24 组完整配方见 [prompt-library.md](prompt-library.md)，机器可读参数见 [prompt-library.json](prompt-library.json)。

## 主体与默认值

主体可以是人物、动物、植物、产品、建筑、交通工具、地貌或抽象形态。先写主体是什么、多少个、有哪些可辨特征，再决定动作或状态。产品画面可直接以产品为唯一中心，建筑画面可直接描写空旷空间。

人物任务未给出人物设定时，使用：25 岁成年女性 Malfoid，铂金长发、翠绿眼睛、黑色圆环耳饰。自然成年比例可按指定画风调整，Q 版可采用三头身、放大的头部与紧凑身体，角色年龄仍为成年。用户文字指定的名称、年龄、外形、服装和物种可以逐项覆盖这些默认值。

默认签名为 `@PLAyfORGE`；可改为指定文字，或留空。签名采用小尺寸细连笔，放在画面的空白角落。主体数量、画内格数与独立图片张数分别写明。

## 拼装顺序

1. **主体与数量**：名称、类别、外形、材质；人物补年龄与服装，多人逐个命名。
2. **主域与媒介**：选择肖像、建筑、产品或其他主域，再用 M 组件确定表达方式。
3. **空间与状态**：S 组件给地点与空间层次，A 组件给动作、接触点或静置关系。
4. **镜头与构图**：C 组件规定看向哪里和看多少，F 组件组织主体位置与空间节奏。
5. **光线与配色**：L 组件确定光的方向和质感，P 组件分配主辅色与强调色。
6. **材质与情绪**：写两三项最有辨识度的表面细节，再用 E 组件把情绪变成可见形状。
7. **文字与输出**：逐项给标题、标签、签名的精确内容和位置；最后给画幅、张数、画内格数。

```text
主体为【名称 / 类别 / 数量 / 外形与材质】，以【主域】为画面目的。
采用【媒介】，场景是【地点 / 时间 / 天气 / 前中后景】。
主体正在【动作或状态】，接触和受力表现为【具体关系】。
镜头为【景别 / 视点 / 焦段感】，构图为【主体位置 / 引导线 / 留白】。
主光【方向 / 软硬 / 色温】，辅光【方向 / 强度】，主辅色为【色组】。
重点刻画【两三项材质】，以【可见细节】形成【情绪】。
文字为【精确内容与布局】，签名为【指定值或留空】。
画幅【比例】，独立图片【张数】，每张画内【主体数 / 格数】。
```

## 约束冲突消解

先采用用户本次的具体文字参数，再用所选配方和组件补齐未写出的部分。同一维度只留下一个明确结果；需要保留两种方向时拆为 A、B 两个完整配方。

| 同时出现的方向 | 组合办法 |
| --- | --- |
| 全身衣装与脸部大特写 | 选择一个主镜头，另一种作为系列中的另一张。 |
| 极简背景与复杂城市 | 把城市降为少量轮廓和灯块，或让主体占比变小以容纳环境。 |
| 平涂与厚重肌理 | 按区域分配：人物平涂，背景厚笔触；或指定一种为主、一种为局部。 |
| 柔光与锋利阴影 | 明确一盏主光和一盏辅光，让硬边只出现在主光直照区域。 |
| 清楚材质与浅景深 | 把重要材质置于同一焦平面，其他层次逐渐柔化。 |
| 单主体与多人互动 | 先确定主体数，再逐人写位置、动作与对应道具。 |
| 多人动作与肢体计数 | 按每个角色分别核对手、脚和可见关节，人数与肢体数量对应。 |
| 产品文字与装饰纹样 | 标签在主视面，纹样移到边缘或背景，文字拥有完整留白。 |
| 竖幅与横向连续故事 | 选择上下格或改变整张画幅，明确格数与格内裁切。 |
| 无字画面与默认签名 | 将签名变量留空，画面保留纯图像。 |
| 指定主体与默认人物 | 以指定主体组成完整画面，默认人物仅补足未设定的人物任务。 |
| 多种高饱和强调色 | 选一个主强调色，其他颜色降饱和或减小面积。 |

## 系列变化方法

先锁定稳定项，再确定变化轴。人物可锁定面部比例、发色、瞳色、耳饰和服装结构；产品可锁定外形、标签、材质和颜色；建筑可锁定结构、材料与空间尺度。

| 变化轴 | 可展开的方向 |
| --- | --- |
| 时间 | 清晨、正午、暮色、午夜。 |
| 天气 | 晴朗、薄雾、细雨、初雪。 |
| 动作 | 准备、进行、完成、短暂停顿。 |
| 情绪 | 平静、期待、怀疑、坚定。 |
| 景别 | 远景、全身、中景、局部近景。 |
| 光线 | 柔天光、窗光、逆光、局部灯光。 |
| 配色 | 保持主体色，改变环境主辅色。 |
| 材质 | 光滑、磨砂、织物、风化、透明。 |
| 空间 | 室内、庭院、都市、自然、幻想场地。 |
| 媒介 | 同一构图的摄影、半厚涂、水彩、版画版本。 |

同媒介系列固定主体与媒介，每次选择一至两个变化轴，让各张区别明确。跨风格组合固定主体，每组独立选择媒介以及适合该媒介的场景、光线与配色。`n` 表示所有组合的总图片数，按组分配；画内格数单独填写。四语翻译对应同一配方，不增加图片数量。先写总张数与分组，再给每张一句差异说明：
