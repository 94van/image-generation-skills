# Malfoid 全领域提示词组合指南 · 中文

## 语言与交付

本技能把任意主体的文字需求组合成完整的文生图提示词，覆盖人物、场景、产品、空间与叙事画面。主体由当前请求决定；产品、建筑、自然与交通工具等非人物主题可独立成画。默认交付提示词；仅当用户要求生成图片时调用图像生成工具。

支持 `language=zh`、`language=en`、`language=ja`、`language=ko`。用户明确指定的语言优先；未指定时跟随当前消息语言。仅在用户要求四语时同时输出中文、English、日本語、한국어，顺序依用户要求。角色名、签名、领域 ID、示例 ID 与 `ar`、`n` 参数保持原样，不翻译、不改变大小写。

默认参数为 `ar=2:3`、`n=1`，签名为右下角一次低调的 `@PLAyfORGE`。用户明确指定的主题、角色、服装、年龄、比例、数量、文案和签名设置均优先于默认值。用户指定的 `n` 表示所有方案合计的独立图片总数；仅当用户明确写“每方案”时才按每个方案计算。若有 `k` 个方案且总数 `n=k`，则每个方案参数为 `n=1`；交付时分别注明总数和各方案数量。提示词的多语翻译不增加图片数；画内分格数量由布局单独指定。

## 组合配方

**选择 1 个领域 + 1 个主媒介 + 1 个场景 + 1 个主要动作 + 镜头 + 光线 + 色板 + 表情。** 将这些要素围绕一个视觉重点连接成自然、具体的提示词，再加入角色锚点、布局和输出参数。

1. **主体与角色：**确定主体是什么、视觉中心在哪里。人物请求未指定人物时，默认使用 Malfoid：25 岁成年女性，浅白金色长发、碧绿眼睛、黑色环形耳环，穿炭灰色高领披风与祖母绿色叠层衣装。非人物请求以所述对象为主体，不自动添加人物。人物系列固定脸部特征、发色、眼色和关键饰品；产品与空间系列固定其形状、结构、材质和色彩特征。
2. **领域与媒介：**从下方选择一个领域，再选择动画赛璐璐、水彩、油画、版画、摄影、黏土或 3D 等一个主媒介。用线条、色块、笔触、材质或镜头质感具体说明媒介效果。
3. **场景与动作：**确定地点、时间、天气、一个主要动作及必要道具；描述重心、手部与物件的接触位置。静物可用摆放、朝向和排列关系代替动作。
4. **镜头与布局：**写明景别、机位、透视、主体位置和前中后景关系。区分全身、半身与特写，给脸、手、产品轮廓或空间动线足够的阅读空间。
5. **光线、色板与情绪：**指定一个主光方向、光线软硬和三至五个主要色彩。把情绪落实为眉眼、嘴角、姿势及环境气氛；静物则使用宁静、锐利、轻盈等视觉气质。
6. **文字与参数：**逐字列出要出现的标题或标签，并指定位置、大小与视觉顺序。确定签名设置、`ar`、`n` 及每幅图的布局。

## 一致性、冲突与系列

明确的当前要求优先于默认设置。同一要素出现多个互斥要求时，采用用户最后明确指定的一项；若依然影响画面方向，先询问一个简短的选择问题。全身与特写、纯平涂与真实摄影等要求各自对应不同方案，不在同一主体上同时堆叠。

选择一个主媒介，最多补充一种相容的表面质感。每幅图保留一个主要动作与一个视觉中心；场景复杂时，通过前景、中景、后景和光线明度分配层次。指定「无其他文字」时，只有明确保留的签名可出现；彻底无字要求同时取消签名。

同媒介系列固定主体锚点和主媒介，每组变化一至两项，例如场景与动作、镜头与情绪、光线与天气。跨风格组合固定主体锚点，每组独立选择一个主媒介，并可搭配适合该媒介的场景、光线与配色。分别给每个方案完整提示词，让每条提示词可以独立使用。

## 提示词与输出模板

```text
语言：zh
领域：一个 domain ID
主体：对象与外观、形状、结构、材质；人物主题另写姓名、年龄、饰品与服装
主媒介：一个主要风格与具体视觉表现
场景：地点、时间、天气及关键物件
动作与情绪：姿态、手部、视线、表情或静物排列
镜头与构图：景别、机位、透视、视觉中心、前中后景
光线与色彩：主光方向、光线软硬、三至五色综合色板
布局与文字：单幅或具体分格；指定文案及位置
签名：@PLAyfORGE，右下角，低调且仅一次
参数：ar=2:3，n=1
```

交付先给一行方案名称，再给可直接使用的完整提示词和参数。用户需要多种风格时，逐个给出独立方案；用户明确要求图片时，使用对应提示词生成并展示图片。

4. **`expression-grid` · 表情网格：**「同一[人物]的[2×3 等分网格]，各格保持相同头部角度、发型、服装和景别，依次呈现[六个具体情绪]，用眉毛、眼睑与嘴角变化表达，格间留一致间距。」

### anime-rain · 雨夜站台

**提示词：**电影感日式动画插画，竖幅 2:3，单张独立画面。Malfoid，一位 25 岁成年女性，浅白金色长发、碧绿眼睛、黑色环形耳环，穿炭灰色高领披风和祖母绿色叠层衣装。雨夜的旧车站月台，腰部以上中近景，人物以三分之四侧面朝向观者，略低机位，位于画面中轴偏左，面容清晰；一只戴手套的手轻扶胸前披风扣，神情冷静，带一丝若有若无的笑意。雨水凝在发梢和披风上，远处铁轨与积水反射青绿色站台灯和暗红霓虹，后景灯牌虚化。细腻连续线稿、边缘明确的双色赛璐璐阴影、成组平涂的发束、柔和辉光与电影景深，面部用简洁动画色块塑造。右下角放置一次小而低调、字形清晰的精确签名 `@PLAyfORGE`，画面无其他文字。参数：`ar=2:3`，`n=1`。
