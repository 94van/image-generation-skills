# 极简 IP 动画制作指南

从角色设计、图层准备到 GIF 编码与验收的完整流程。默认输出 1:1、512×512、400 帧、20ms/帧、8 秒的无限循环动画。

## 1. 制作流程

| 环节 | 方法 | 产物 |
| --- | --- | --- |
| 角色设计 | 图像生成工具与设计提示词 | 独立静态角色图 |
| 分层 | 图像编辑、透明蒙版、关节与眼睛定位 | RGBA PNG 图层与 rig.json |
| 动画 | Python + Pillow 二维图层变换 | 连续动画帧 |
| 编码与验收 | 共用调色板、GIF 编码、逐帧解码、视觉检查 | GIF、规格报告与预览 |

角色保持清晰轮廓、少量配色、完整友善的眼睛；底部可放置纤细的复古打字机字体。默认动作是眨眼、小幅点头与适配身体结构的移动，不挥手、不新增肢体。品牌、角色、数量与规格均可调整。

## 2. 设计方向

| 视觉方向 | 结构与配色示例 | 适配动作 |
| --- | --- | --- |
| 瑞士现代主义 | 黑方头、红色天线、奶油留白 | 无腿弹跳 |
| 日式单线 | 水滴轮廓、少量线条、暖白 | 无腿轻跳 |
| 包豪斯 | 蓝半圆、红三角、黑细腿 | 交替步行 |
| 北欧软几何 | 绿色拱形、粉灰底、短足 | 碎步 |
| 字母构形 | 字母负空间、单支撑 | 单支撑弹动 |
| 陶瓷产品雕塑 | 白蛋形、黑面罩、薄荷眼 | 分离小脚步行 |
| 复古像素 | 珊瑚菱形、深梅色底、长腿 | 像素步行 |
| 装饰艺术 | 金色收束轮廓、黑底 | 基座弹跳 |
| 折纸丝带 | 折面、几何眼睛 | 弹簧式弹动 |
| 轨道机器人 | 椭圆主体、轨道环、多足 | 多足爬行 |

多款设计应先区分剪影、体块与负空间，缩小到 64px 后仍能辨认。每款独立输出，数量参数表示独立设计与文件数。

## 3. 准备图层

保留原图副本。全部 PNG 使用相同尺寸的 RGBA 画布，准备 body、head、eyes、各只 feet 和固定文字 overlay；在 [rig.json](rig.md) 标注枢轴、眼睛中心、脚关节与地面位置。

先从脸底移除原眼，补齐脸色及 alpha，再叠加眼睛层。浅色身体宜用轮廓蒙版区分背景，避免阈值抠图误删主体。清除原阴影与旧文字，防止移动后残留。

脚层保留关节重叠区，逐个确认旋转中心。局部眨眼需要独立眼层，局部点头需要独立头层；单体角色可采用整体轻压表达回应。

## 4. 表情曲线

眨眼分为约 70ms 合眼、40ms 闭合、130ms 睁眼，在 20ms 帧间隔下采样。双眼通常同步，局部压缩最低保留约 4% 眼高；也可使用专门绘制的闭眼弧线。

8 秒片段可使用 0.55、2.48、4.42、4.73、6.53 秒作为眨眼起点，其中相邻的 4.42/4.73 秒形成双眨。眼位随所属头层移动，避免逐帧随机偏移。

点头围绕颈部枢轴轻转 2–4°，可配合少量垂直缩放。身体与固定文字保持稳定。

## 5. 移动方式

### 无腿与单支撑：弹跳

一个周期分为 0–18% 预压、18–88% 腾空、88–100% 落地恢复。预压纵向约 14%，落地约 18%，横向补偿约纵向压缩的 0.65 倍；腾空高度约画幅的 4–6%。

以角色底面为缩放锚点。腾空时阴影缩小变淡，落地时扩展，检查足底位置与地面接触。

### 双足：步行与碎步

双脚相差半周期，一脚支撑、一脚摆动。短腿使用小摆角与小幅起伏，长腿需要清晰的膝关节和脚底轨迹。渲染器提供绕关节摆动的基础实现；稳定接地需要进一步加入支撑阶段的世界坐标足底锁定与离地回收轨迹。

### 多足：爬行

三只或更多脚按支撑序列错相，保持合理接触点，配合小幅身体俯仰和短行程。渲染器要求 walk 至少两只脚层，crawl 至少三只；无腿结构使用弹跳。

## 6. 跟随镜头与循环

二维跟随让角色保持画面中部，地面标记反向滚动，尺度从约 0.96 推至 1.08，文字固定于画框。

默认 8 秒镜头前 6 秒缓推、后 2 秒平滑回归。持续单向推近可采用非循环视频，或设计转场衔接。使用 smoothstep：s(x)=3x²−2x³，使段首段尾速度趋零。

周期动作在片长内完成整数周期；最后一帧时间取 (N−1)/fps。对照首尾与相邻帧，检查位置和速度连续性。

## 7. GIF 编码

帧延时使用 10ms 的整数倍；20ms 对应标称 50fps，实际播放速度取决于播放器和设备。

从多帧采样生成约 192 色的共用调色板，减少颜色闪烁。极简平面图默认关闭抖动，渐变图需平衡色带与体积。GIF 不支持完整半透明，先合成到选定底色。

先生成完整编码字节，写入 `.pending` 文件，再原子替换目标。设置无限循环与适当帧清除方式，保存后重新逐帧解码。

512×512×400 的 RGB 帧约占 300MiB，处理过程的峰值内存更高。多角色串行渲染；高分辨率长片段宜采用流式或分段方案。

## 8. 运行示例

在 Skill 根目录安装 requirements.txt 中的依赖后运行：

```bash
python scripts/make_demo.py ./work/demo
python scripts/render_gif.py ./work/demo/rig.json ./work/demo/demo.gif
python scripts/validate_gif.py ./work/demo/demo.gif --size 512 --frames 400 --duration-ms 20
```

示例生成器创建几何机器人图层与配置。用于其他角色时，替换 PNG，分别设置眼位、枢轴、脚关节及动作模式。图层需预先准备，渲染器按配置驱动二维变换。

## 9. 验收与交付

机器检查：GIF 格式、完整解码、尺寸、帧数、逐帧延时、总时长、无限循环、帧内容变化、SHA256 和文件大小。首尾平均像素差用于定位衔接问题。

视觉检查：闭眼完整、头眼联动、肢体与关节完整、接地稳定、文字清晰、边缘干净、镜头平稳、首尾过渡自然。

交付独立 GIF、分层与 rig、规格报告和预览；多款可附合集。实际支持的功能以图层、动画轨道与检验结果为准。

## 10. 排错

| 问题 | 检查与处理 |
| --- | --- |
| 静止或重复帧 | 检查动画轨道与逐帧内容差异 |
| 眼睛闭合不完整 | 移除脸底原眼，修补脸色与 alpha |
| 动作多出挥手 | 移除手臂动画轨道，保留既定姿态 |
| 滑步 | 设置接地窗口，锁定支撑脚世界坐标 |
| 跳跃缺乏重量 | 调整底部锚点、预压、落地恢复与阴影 |
| 循环跳帧 | 检查整数周期、镜头回归与首尾速度 |
| 文件不完整 | 使用原子保存，重新逐帧解码 |
| 文件过大 | 优先优化尺寸与配色，调整帧率时同步规格 |
