# 可复制母提示词

## 静态角色设计

```text
为品牌「[品牌名，默认 PlayForge]」设计 [n] 款彼此独立的极简 [角色，默认 AI robot] IP。每款一张独立 1:1 图，完整角色、充分留白、少量精确配色、轮廓与负空间清楚。每款必须在体块、结构与剪影上明显不同，缩到 64px 仍可区分，不是同一个角色换颜色。

方向：[瑞士现代主义 / 日式单线 / 包豪斯 / 北欧软几何 / 字母负空间 / 陶瓷雕塑 / 复古像素 / 装饰艺术 / 折纸丝带 / 轨道结构，按需选择或自定义]。
角色双眼完整、友善、可爱，避免密集眼睛或恐怖感。底部用细小纤细的复古打字机字体环绕排入「[精确品牌文字]」，文字不压住角色。动画将按原有结构制作，头部、眼睛、脚的轮廓和关节关系应便于分层。不要为了动画添加不存在的手脚，不做挥手姿势循环。
输出静态设计图；不要声称此图已经是 GIF 或已经自动拆层。
```

## 从已有角色到 GIF 的 Agent 任务母版

```text
使用 $94van-ip-gif-studio，将 [原图或分层路径] 制作为真实 GIF。
保持角色身份、轮廓、配色与现有肢体，禁止新增手脚，默认不要挥手。
先修复底层原眼，拆分眼睛、头部、现有脚和底部文字，核对枢轴与关节。
持续自然眨眼，小幅点头；无腿 Q 弹跳，双足走动，多足爬行，单支撑轻弹，按实际结构选择。
规格：[512]×[512]，[400] 帧，每帧 [20]ms，总长 [8] 秒，标称 [50]fps，无限循环。
底部固定细小复古打字机字体「[品牌]」；镜头二维缓推并平滑回归，需明确循环中的回归段。
统一调色板、原子保存、逐帧解码校验，并检查残眼、关节破裂、接地、文字与首尾衔接。
交付每款独立 GIF、rig/分层、规格报告与预览。基础脚摆角若存在滑步，标明演示局限，不能声称达到真实步态。
```

`n` 是文件/设计数量，`frames` 是单个文件帧数，二者不得混淆。母版中的一致规格应同步计算；用户提供相互冲突的时长/帧率/帧数时先解决冲突。
