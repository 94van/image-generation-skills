# 灵动造物 · 动画样板

![几何机器人眨眼、轻点头与弹跳](demo.gif)

几何机器人以局部眨眼、轻微点头和弹跳呈现动态表情，搭配固定环形文字与缓推回归镜头。由 `make_demo.py` 创建图层，`render_gif.py` 完成动画渲染。

## 规格

| 项目 | 数值 |
| --- | --- |
| 尺寸 | 512×512 |
| 帧数 | 400 |
| 帧延时 | 20ms |
| 总时长 | 8 秒 |
| 平均帧率 | 50fps |
| 循环 | 无限 |
| 不同内容帧 | 399 |

[逐帧校验报告](validation.json)包含完整解码结果、文件大小与 SHA256。[关键帧拼图](contact-sheet.png)展示开启、闭合、睁眼、升降和首尾状态。

## 验证范围

已完成逐帧解码与关键帧检查；实时播放流畅度需在目标播放器中确认。首尾平均像素差约 3.01，供衔接检查参考。样板覆盖眨眼、点头与弹跳；步行和爬行需使用相应脚层配置。

## 复现与替换

安装依赖后，在 Skill 根目录执行 README 中的示例命令。替换角色时使用自己的图层与 rig 配置，重新设置眼位、头部枢轴、地面及关节。环形文字采用环境中可用字体，正式应用时可替换为品牌字体并校对小尺寸显示效果。
