# 94｜PLAyfORGE CHARACTER ESSENTIALS GENERATOR

把「参照图深度拆解」和「角色身份自适配」合并为双路径生成流程。固定图鉴构图逻辑，让人物、服装、道具、配色和符号随输入变化。不要把示例中的马尔福、女性化造型、斯莱特林、蛇、祖母绿或内搭套装变成所有角色的默认设定。

## 输入与默认值

接收自然语言即可，不要求用户填写整张表。沿用本次创作中已明确的配置；用户修改优先于默认值。

| 参数 | 默认与语义 |
| --- | --- |
| `mode` | `AUTO`；可用 `REFERENCE`、`CHARACTER`、`HYBRID` |
| `character` / `work` | 目标角色与所属作品；可从图中识别，作品可为 `AUTO` 或原创 OC |
| `references` | 用户提供的图片；逐张确定其人物、服饰、风格或构图用途 |
| `theme` | `AUTO`；衣橱与服饰、装备与武器、生活用品与收藏、综合 Essentials |
| `ar` | `4:7` 竖版；接受用户指定的其他比例并重新排布 |
| `n` | `1`，正整数；是本次请求的独立成品总张数，`N=5` 等同 `n=5` |
| `style` | 精致日系二维角色设定集，细线、柔和复古水彩与轻柔赛璐璐阴影 |
| `signature` | 暗水印中的作者标识，默认 `@PLAyfORGE_`，精确保留大小写与末尾下划线；绝不绘制成可见文字 |
| `watermark` | 默认 `invisible`：在最终 PNG 中写入可提取的隐形标识；`off` 或 `signature=NONE` 关闭 |
| `output` | 要「提示词」时交付文本；要「生成图／做图」时调用可用生图工具；未指明时交付提示词 |

「完全无文字」关闭标题、物品标签和道具字样，但仍保留不可见暗水印；用户明确要求「无水印／无暗水印」或关闭签名参数时才关闭嵌入。提示词语言跟随用户；画内文字默认仅角色英文名与 `E S S E N T I A L S`，没有可见品牌签名。

## 四模式路由

显式模式优先；`AUTO` 是路由器，不是独立的随意创作模式。

| 输入 | 执行模式 | 信息来源 |
| --- | --- | --- |
| 有可见参照图，未指定替换角色 | `REFERENCE` | 图中主体、服饰和材质为依据 |
| 无参照图，有角色名称或 OC 描述 | `CHARACTER` | 指定版本的角色身份、世界观和标志元素 |
| 有参照图，同时明确替换为另一角色或借用图的风格／布局 | `HYBRID` | 目标角色负责身份和物品，参照图负责指定的视觉层面 |
| 有图并写出图中同一角色的名字 | `REFERENCE` | 名字是身份补充，不自动视为替换 |
| 无图、无角色、无可用角色描述 | 待补充 | 只问目标角色或参照图；不默认生成马尔福 |

`REFERENCE` 缺图、`HYBRID` 缺图或缺目标角色时，说明缺少的输入并索取；不悄悄降级成另一模式。显式 `CHARACTER` 不需要图，不擅自吸收无关附件。角色同名、版本冲突或多图用途不清且会改变主体时，只澄清这个关键点。

## 执行流程

1. **确定输出和模式。** 默认用一句话说明采用的模式和必要假设；用户只要提示词时省略说明。已经明确的信息不重复询问。
2. **建立角色与物品蓝图。** 按需读取 [双路径拆解规则](references/adaptation.md)：REFERENCE 用路径 A，CHARACTER 用路径 B，HYBRID 读两条路径和迁移规则。检查实际可见图片；将可见事实、已知设定与创作补全分开，不能把补全写成观察结果或官方设定。
3. **自动设计。** 锁定身份、年龄表现、发型脸部、体型、核心服饰和标志符号。按主题挑选有角色关联的服装、装备、生活用品；为空缺部分设计合理的细节。中央人物穿着适合身份和年龄的完整服装或不透明基础搭配，不默认脱衣、性别转换或改成成年版本。
4. **编写完整提示词。** 读取 [通用母提示词](references/master-prompt.md)，展开全部变量，落实人物姿态、中央穿搭、左右物品、材质、色彩、标题和留白。画面中禁止绘制作者标识；暗水印交给生成后的实际嵌入步骤。每张自成一体，不能只写「同上」或把识别工作丢给生图模型。
5. **按张输出。** 为 `n` 张列出 `01…n`，每张一个提示词、一个独立画面；多角色列表也按单张单角色分配。未指定每个角色各几张时，`n` 计总量。固定身份与构图，只适度变化姿态、穿搭或物品组合；严格复刻时保持参考一致，不强行增加变化。
6. **检查画面。** 文本请求检查提示词；图片请求先确认本轮可用工具并遵守其调用要求，传入真实参照图，为各张执行独立生成。检查返回图的全身完整性、肢体、物品、文字与张数；只针对失败图修正，不无限重试。工具不可用或某张失败时如实交付可用提示词或已完成图片，明确剩余数量，不能把提示词当作已生成图片。
7. **嵌入并核验暗水印。** 图片完成所有尺寸、裁切和修复后，读取 [暗水印说明](references/watermark.md)，运行随包脚本为每张最终 PNG 写入作者标识、唯一作品 ID 与源文件哈希，提取核验后交付带水印的 PNG 和 manifest。只在脚本成功且提取一致时声称已加水印；仅生成提示词时通常注明尚未嵌入，用户只要提示词时可省略额外说明，但绝不声称已经嵌入。图片请求中缺少可读图片文件或脚本执行失败时，必须报告未完成嵌入。不要指望生图模型靠文字提示实现可靠的不可见编码。

图像工具不支持所选精确比例时，优先选方向一致且比例接近的尺寸（默认 `4:7` 对应竖版），并用工具允许的补边／编辑保留人物与全部物品；不要裁掉脚或压扁人物来凑比例。报告实际尺寸，未达到时不要声称已达成精确比例。

## 每张的构图与质量约束

- 一张完整插画，默认竖版，方向随所选比例调整；一个中央全身角色，头顶至脚部／鞋底完整可见。人物宽约 40%、高约 84% 是默认竖版的排布参考，需给标题及上下边缘留出余量；方形或横版需重新安排物品密度和人物占比。
- 左右均衡但不机械镜像；每件服饰道具独立悬浮、完整可辨，保留间距，不遮挡人物面部、手脚或相邻物品。鞋袜可以成对成组，但不能融合成一件。
- 不画拼图、九宫格、漫画分镜、多个画框、照片拼接或重复全身角色；不增加头像、背面人物和人体局部小窗。周边服饰展示为空衣物，不能带着悬空手脚或人体模型。
- 双臂、双腿、关节和手脚结构自然；人类可见的手脚符合正常指／趾数量，没有融合、重复、错位、截肢。不要为了数手指而强迫露出被自然遮挡的手指；非人类角色遵守其设定的肢体结构。
- 默认采用浅奶油纸质背景、轻薄线稿和清晰服饰材质，配色和装饰由当前角色决定；不在不同世界观之间混用徽章、魔杖、蛇纹等符号。明确要求其他风格时随之适配。
- 默认中央穿搭不透明、非挑逗；未成年或年龄不明确的角色使用适龄完整服饰，不使用成人内衣或性化姿态。用户明确选择成年角色的内搭设计时，按服装图鉴呈现，不透明且非露骨。
- 默认顶部两行角色英文名与 `E S S E N T I A L S`；底部不绘制签名、用户名、Logo 或肉眼可见的水印。`@PLAyfORGE_` 只作为暗水印数据，不占画面位置。
- 暗水印支持原始无损 PNG 的提取追踪；截图、裁剪、缩放、重新编码或平台重压缩可能破坏它。元数据标签和低透明度可见字样都不能冒充已验证的隐形像素水印；不声称抗任意编辑、加密或版权认证。

## 交付格式

提示词请求：默认给简短配置说明，随后每张一个可复制完整提示词和参数（`mode`、`ar`、`n=1`、暗水印作者标识）；注明暗水印需生成后实际嵌入，必要时在画外附一句「哪些细节为设计补全」。用户明确只要提示词或指定其他格式时，以用户格式为准，省略额外说明；来源区分保留在内部蓝图，不让它变成画内文字。图片请求：交付实际独立成品 PNG、追踪 manifest 和需要说明的偏差，不默认输出冗长分析。批次总数留在任务说明里，单张渲染提示词中只要求一张，避免模型把 `n=5` 画成五联图。

需要调用示范或验证路由时，读 [调用与完整提示词示例](examples/usage.md)。这些是文本示例，不是已经生成或验证通过的样图。
