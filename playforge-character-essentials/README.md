# 94｜PLAyfORGE CHARACTER ESSENTIALS GENERATOR

将参照图或角色描述转成「中央单角色全身＋周围服饰道具悬浮陈列」的角色图鉴。支持现有作品角色、原创 OC 与用户指定的造型改编；人物、穿搭、物品、材质和配色均随输入自适配。

默认 **4:7 竖版、单张完整图鉴、不可见暗水印作者标识 `@PLAyfORGE_`**。图片表面不显示签名；生成后通过随包脚本嵌入并提取核验，附作品 ID 与追踪清单。要求 5 张时交付 5 个独立画面，不生成五联图。

## 四种模式

| 模式 | 用法 |
| --- | --- |
| `AUTO` | 根据图片、角色信息和替换意图选择下列路径 |
| `REFERENCE` | 保留参照图主体和关键视觉特征，拆解可见服装与物件 |
| `CHARACTER` | 根据角色身份、世界观、气质与代表元素自动设计 |
| `HYBRID` | 用目标角色的身份与物品，迁移参照图指定的画风／陈列方式 |

图片加图中同一角色的名字仍走 REFERENCE；明确替换角色才走 HYBRID。看不见的细节会区分为设计补全，不冒充参考图事实。

## 安装与调用

从仓库根目录复制整个 Skill 文件夹：

```bash
mkdir -p ~/.codex/skills
cp -R playforge-character-essentials ~/.codex/skills/
```

自定义 `CODEX_HOME` 时使用对应的 `skills` 目录。安装后按 Agent 的方式重新加载；仓库中的文件不会自动安装到本机。

```text
使用 $playforge-character-essentials，mode=AUTO。
我的 OC 是 28 岁高山邮差 MIRA，黑色短卷发、棕色眼睛、深棕皮肤，主色靛蓝和赭黄。
给我 1 条完整的 4:7 衣橱图鉴提示词，画面不显示签名，暗水印作者标识为 @PLAyfORGE_。
```

```text
使用 $playforge-character-essentials，按附图做 REFERENCE 深度拆解。
保留人物、核心服装、材质和配色，补全缺失部分时在画外说明。
生成 5 张独立图鉴，每张只放一个完整全身角色。
```

附图调用需要实际提供可读取图片。提出「提示词」时输出文本；提出「生成图」时使用当前环境可用的图像生成工具。本 Skill 不自带图像服务、API 密钥或固定平台依赖。没有生图工具时可完成提示词设计，但不能声称已生成图片或嵌入水印。暗水印脚本使用 Python 与 Pillow，在实际成图后运行，不能仅靠提示词完成隐形编码。

## 输出约定

- 单角色、全身完整；周边衣物是空衣物，不附着人体部件。
- 人物身份、年龄与服装随输入变化，不默认套用马尔福、女性造型、学院配色或成人内搭。
- 批次每张提示词均完整独立，图像逐张生成与检查。
- 用户可改比例、画风、暗水印作者标识与主题；完全无文字时关闭画内标题和标签，暗水印仍保留，明确要求无水印时才关闭。
- `examples/usage.md` 是文本示范，没有将未生成图片冒充样图。图片的肢体、文字和精确画幅仍需在实际生成后检查。
- 暗水印可从原始无损 PNG 提取，并用随图 manifest 核对；截图、裁剪、缩放、平台重压缩可能破坏标识。它不是加密、强认证或保证永久保留的水印。
