# 调用与提示词示例

以下是调用文本和完整提示词示范，未附生成图片，不代表已完成生图或图像质量测试。附件名称描述用户应提供的资料；不是随包附带的参考图。

## AUTO：只给角色描述

```text
使用 $playforge-character-essentials。
mode=AUTO，角色是原创 OC「MIRA」：28 岁女性高山邮差，黑色短卷发、棕色眼睛、深棕皮肤，沉着友好。
主色靛蓝和赭黄，偏实用复古旅行服。做一张综合 Essentials 图鉴提示词。
```

路由为 CHARACTER；默认 `ar=4:7`、`n=1`、暗水印作者标识 `@PLAyfORGE_`，画面不显示签名。无需用户另列衣橱清单；文本提示词本身没有嵌入水印。

## REFERENCE：根据实际附图拆解

```text
使用 $playforge-character-essentials，mode=REFERENCE。
请看我附上的角色立绘，把可见服装、配饰与道具拆成衣橱图鉴，保留人物外貌和原配色。
只陈列图中已有物品；半身图缺少的裤装、鞋子请合理补全并在画外说明。
输出 1 张的完整提示词，4:7。
```

先检查实际附图。图中物品为「可见」，补出的裤装鞋子只供中央全身人物穿着并标为「设计补全」，不擅自扩写图外陈列品。没有实际附件时只请求图片，不声称已识别。

## CHARACTER：角色自适配与批量

```text
使用 $playforge-character-essentials，mode=CHARACTER。
角色：原创 OC ORIN，45 岁男性沙漠机械师，铜红短发，橄榄色工装，黄铜护目镜。
主题：装备与生活用品，N=5，ar=4:7。
请生成 5 张独立图鉴，保持同一身份，分别围绕日常检修、沙地出行、夜间维修、工坊收藏和节日休息设计。
```

应调用可用工具逐张生成，总共 5 个独立画面；每张只出现 ORIN 一次，随后分别写入作者标识为 `@PLAyfORGE_`、作品 ID 各不相同的暗水印，提取核验后交付 PNG 与清单。若改为「只给提示词」，则交付 5 条完整可复制提示词，不声称已有水印。不要输出五联图或在每条末尾写 `n=5` 导致总数变成 25。

## HYBRID：参考视觉语法，替换身份

```text
使用 $playforge-character-essentials，mode=HYBRID。
参考我附的魔法学院衣橱图鉴的细线、水彩、纸质和左右陈列方式。
目标人物换成 ORIN：45 岁男性沙漠机械师，铜红短发、橄榄色工装、黄铜护目镜。
服装、配色、徽章和工具按 ORIN 重设计，不保留学院标志。输出 1 条完整提示词。
```

身份、服装、道具、主体配色来自 ORIN；笔触、纸感和布局节奏来自附图。即使省略 `mode` 或写 `AUTO`，明确的替换要求仍应路由到 HYBRID。

## 一个已展开的单张提示词

配置：`mode=CHARACTER` · `character=MIRA` · `ar=4:7` · `n=1` · `watermark=invisible` · `signature=@PLAyfORGE_`。水印配置用于生成后的脚本步骤，不作为画内文字。
MIRA 的外貌、年龄与主色来自上述用户设定；服装剪裁和物件是为该 OC 创作的设计补全。

```text
生成一张独立完整的 4:7 竖版 MIRA ESSENTIALS 角色衣橱与专属物品图鉴。

精致日系二维角色设定集，细而干净的暖灰线稿，轻柔赛璐璐阴影和柔和复古水彩晕染，浅奶油纸纹背景。服装、皮革、黄铜、纸张和玻璃各有清晰材质。画面精细克制，浅背景衬托靛蓝与赭黄，不采用三维渲染、摄影、厚重黑描边或粗糙草图。

中央只出现一位 MIRA：28 岁成年女性高山邮差，深棕皮肤、黑色短卷发、棕色眼睛，身形结实自然，沉着友好。正面轻微四分之三站姿，两脚稳稳落地，一只手放松垂下，另一只手轻扶衣领，手指自然弯曲。头顶、发梢、双手和靴底完整可见，不切边，不添加额外身体部件。

她穿不透明的暖米色长袖衬衫、靛蓝实用马甲、赭黄直筒长裤和深棕系带短靴。马甲有黄铜扣、细密缝线与一枚原创信封形小徽章；腰间皮革细腰带连接钥匙环。穿搭适合山地步行，面料略有使用痕迹但整洁，褶皱、扣件、鞋带与衣物层次真实合理。

一个中央全身角色，周围独立悬浮陈列衣橱与邮差用品，左右均衡但不机械镜像。人物宽约 40%、高约 84%，同时为顶部标题与脚下边缘留下充足空白。不是拼图、分镜、九宫格、多视图或照片拼接。

左侧从上到下依次完整陈列：
1. 靛蓝防风短斗篷，赭黄棉布内衬、黄铜搭扣和细密边线，展开可见完整衣身，无人体。
2. 米白细针织备用开衫，圆领、木质纽扣和清晰袖口。
3. 一双赭黄粗针织长袜，两只形状分明、罗纹袜口完整。
4. 深棕备用皮革手套，一对分离摆放，保留清楚的手套指部轮廓，内部没有手。
5. 一卷束有靛蓝绳带的折叠山路地图，仅有细线地形纹路，不含小字标签。

右侧从上到下依次完整陈列：
1. 深棕皮革邮差包，黄铜双扣、加固缝线和信封形原创徽章，肩带盘绕清楚。
2. 黄铜指南针，奶油色盘面与清晰方向指针，不含细碎字母。
3. 一组奶油色信封，赭黄火漆与深蓝细绳，边缘完整，无收件人文字。
4. 小型复古玻璃水壶，深棕皮套和靛蓝提绳。
5. 赭黄布面路线记录册与一支短木铅笔，书面无文字，两件彼此分开。

每件服饰和道具独立悬浮、形状完整、不融合、有清晰间距；不挡住 MIRA 的面部、手脚或其他物件。较大衣物靠两侧上部，小物向下疏朗排列，不放第二个人、头像或人体局部。装饰仅有极少量山峰折线与邮路圆点，保持负空间，不出现魔杖、蛇徽或学院领带。

顶部居中精确写 MIRA，使用纤细复古衬线字；第二行精确写 E S S E N T I A L S，字号更小、字距舒展。底部与任何其他位置都不显示作者签名、用户名、Logo 或可见水印；靴底下方保持干净留白。画内没有其他文字、编号或说明标签。

高完成度角色时装插画，清楚的材质、流畅的线条与统一绘制精度。肢体与关节自然，没有多余手臂、腿、手掌、脚掌或融合手指；悬浮衣物内没有人头、手脚或人台。不要裁切人物、物件或标题，不要文字乱码、可见签名或拥挤背景。

本次只生成这一张完整的 4:7 MIRA ESSENTIALS 图鉴，一个全身人物，左右分离的衣橱和邮差用品，不显示作者标识，不画多格合成。
```

实际生成后，按 [暗水印说明](../references/watermark.md) 为最终 PNG 嵌入 `@PLAyfORGE_` 与唯一作品 ID，并提取核验。此处未生成图片，因此没有声称已完成嵌入。

## 边界调用

| 请求 | 应有行为 |
| --- | --- |
| `AUTO`，未提供角色或图片 | 只询问角色名称／描述或参照图 |
| 附 MIRA 图并写「这是 MIRA，做图鉴」 | REFERENCE，名字是身份补充 |
| `REFERENCE`，附件未成功传入 | 请求实际图片，不假装看见 |
| 儿童探险角色的衣橱 | 适龄完整服装，保持原年龄，不套成人内搭 |
| `n=3`，给出三名角色 | 三张独立图鉴，每张一名，不画合影 |
| 两名角色，`n=5`，未指定分配 | 说明合理分配（如 3+2），总量仍为 5 |
| 十名角色、`n=5` 且要求全部覆盖 | 只澄清数量冲突，不能把两人合进一张来凑数 |
| 「完全无文字」 | 关闭所有画内文字，仍执行不可见暗水印步骤 |
| 「只去掉顶部标题」 | 去标题，仍执行不可见暗水印步骤 |
| 「不要任何水印」或 `watermark=off` | 不写暗水印，也不绘制可见签名 |
| 仅收到提示词，没有实际成图 | 只提供水印配置，不声称已嵌入 |
